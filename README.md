# Anime Renamer

Docker + 网页界面的动画批量重命名工具：扫描媒体目录 → 自动匹配 TMDB → 预览 → 一键改名/整理成
Jellyfin 媒体库结构，所有操作可撤销。

## 快速开始

```bash
mkdir -p config media
cp config/settings.example.json config/settings.json   # 填入 TMDB API Key
docker compose up -d --build
```

浏览器打开 <http://localhost:8080>，然后在「设置」页填写 TMDB API Key 也可以。

目录说明：
- `media/`：放动画的目录（容器内为 `/media`）
- `config/`：设置、预设、识别规则与执行历史（容器内为 `/config`）

## 使用流程

1. **扫描**：选择媒体目录，点「开始扫描」。
2. **匹配作品**：点「一键自动匹配 TMDB」，唯一确定的作品自动套用，不确定的从下拉框选择。
3. **模板与预览**：编辑三种命名规则（正片 / 特典 / 剧场版），右侧预览会实时更新。
   字幕、特典目录、冲突处理等工作流设置统一在「设置」页修改，对所有预设生效。
4. **执行改名**：确认后执行；执行记录在下方，可一键撤销。

## 访问密码

默认不设密码，直接打开就能用。想保护自己的媒体库，可以在「设置」页开启访问密码（可设置、修改、关闭）：

- 密码只保存不可逆哈希，不存明文，也不会出现在日志和界面上。
- 开启后打开网页先进登录页，登录状态约保留 7 天，也可以随时点「退出登录」。
- 连续输错 5 次会临时锁定 5 分钟。

**忘记密码怎么办**：手工编辑 `config/settings.json`，删除其中的 `"auth"` 整段（包括 `password_hash`），保存后重启容器，就会回到无需密码的状态。

## 几个使用提醒

- **合集文件**：文件名里带区间或合集写法（如 `01-12`、`EP01-12`、`1-12话`、`合集`、`Complete`、`全12话`）的视频会被单独标记为「合集」，不会被当成单集命名。程序不拆集（拆分需要重新编码），需要到「匹配作品」页手动选择「原样搬运」或「指定季存放」；不做选择就不会自动执行。
- **网盘场景**：推荐勾选「只重命名文件」模式。同一个目录里改名不会产生数据搬运，比移动到新目录快得多。
- **扫描上限**：默认每次最多扫描 2 万个文件，可在「设置」页调到最多 10 万。调高上限会占用更多内存、扫描更久、TMDB 请求也更多，建议同时开启扫描结果保存，分几次处理。

## 配置文件

| 文件 | 内容 |
|---|---|
| `config/settings.json` | 全局设置（解析、命名、TMDB、执行策略、访问密码） |
| `config/presets.json` | 命名预设（三种命名规则 + 一份设置快照） |
| `config/rules.json` | 文件名识别规则 |
| `config/app.db` | 执行历史 / 撤销记录 / 扫描结果 / 登录会话 |

配置文件可手工编辑，改完重启容器生效。
